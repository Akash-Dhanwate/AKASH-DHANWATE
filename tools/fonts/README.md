# Display lettering

Space Grotesk by Florian Karsten is licensed under the SIL Open Font License 1.1 in `OFL.txt`. The generator uses the Latin 700 WOFF supplied by the development dependency `@fontsource/space-grotesk`.

Source: https://github.com/floriankarsten/space-grotesk

The asset generator converts display lettering to paths. GitHub visitors do not download this font or rely on installed web fonts. Small SVG labels use the local `ui-monospace, SFMono-Regular, Consolas, monospace` stack; Markdown uses GitHub's native typeface.
